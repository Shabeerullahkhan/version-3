# DWG Editor - Web-Based CAD Drawing Tool

Accurate web-based DWG/DXF editor with distance calculation and full geometry control.

## Features

✅ Accurate DWG/DXF rendering  
✅ Distance calculation between lines  
✅ Full geometry control  
✅ Interactive canvas with zoom/pan  
✅ Properties panel  
✅ Entity browser  

## Quick Start

```bash
npm install
npm run dev
```

## Usage

1. **Open File** - Click "Open" button and select .dxf or .json
2. **Select Line** - Click any line (turns red)
3. **View Properties** - See details in right panel
4. **Measure Distance** - Click "Measure to Another Line" then select target
5. **Navigate** - Mouse wheel to zoom, drag to pan

## Supported Formats

- DXF (AutoCAD format)
- JSON (simple format)

## File Support

Accepts all file types in file picker - only .dxf and .json will parse correctly. Other formats will show error message.
